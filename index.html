Ecommerce

This is an e-commerce backend API built with Express.js and MySQL using Sequelize. Developers can use it to manage their product catalog, including categories, individual products, and associated tags. The API provides RESTful endpoints for creating, reading, updating, and deleting this data. Users can easily set up a development database with sample information and start testing the CRUD functionality right away, using tools like Postman or Insomnia.

SQL Employe Database

This is a command-line interface (CLI) application for managing employee data. It connects to a MySQL database using Sequelize to handle CRUD operations for departments, roles, and employees. Users can view existing records and add new ones through an interactive menu system. The CLI provides a simple and efficient way to maintain employee information.

Social Network API

This is a social network API built with Node.js, Express.js, and MongoDB. It allows users to create profiles, share "thoughts", react to others' thoughts, and manage friendships. The API provides full CRUD functionality through its RESTful endpoints, which can be easily tested and explored using a tool like Insomnia
